## Knowledge Gained from the Project

1. Data Collection & Integration

- Learned how to call and handle data from external APIs (Open-Meteo).
- Gained experience in working with JSON responses and converting them into structured formats using Python & pandas.

2. ETL Pipeline Development

- Built reusable Python scripts to clean, transform, and load data.
- Understood schema design and how to optimize data models for analytics in BigQuery.

3. Data Storage & Management

- Designed datasets, tables, and partitions in BigQuery.
- Applied SQL for querying and validation of data integrity.

4. Dashboard Development

- Created interactive dashboards with Dash & Plotly for custom visualization.
- Learned how to connect a dashboard to BigQuery as a live data source.

5. Deployment & Automation

- Deployed the dashboard using Render.
- Packaged applications with GitHub and Docker for reproducibility.
- Automated ETL processes using GitHub Actions & cron jobs.

6. Web Analytics Integration

- Implemented GA4 and GTM to track user behavior on the dashboard.
- Captured and analyzed event data (e.g., page views, button clicks, dropdown selections).
- Exported GA4 event data into BigQuery for deeper analysis.

7. Business Intelligence (BI) Reporting

- Built self-service dashboards in Looker Studio.

8. Machine Learning Applications

- Applied regression models to predict future temperatures.
- Built classification models to forecast whether a day would be rainy.
- Used clustering techniques to group days with similar weather conditions.
- Gained experience with scikit-learn workflows (preprocessing, model training, evaluation).

## Tools Applied in the Project

1. Programming & Data Processing: Python, pandas, requests
2. ETL & Orchestration: google-cloud-bigquery, GitHub Actions, cron
3. Data Storage: Google BigQuery, BigQuery Console
4. Dashboard Development: Dash, Plotly
5. Deployment: Render, GitHub
6. Web Analytics: Google Tag Manager (GTM), Google Analytics 4 (GA4)
7. Business Intelligence: Looker Studio (BigQuery connector)
8. Machine Learning: scikit-learn
